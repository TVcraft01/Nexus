Nexus GUI file-fetch walkthrough — recorded evidence
====================================================

What: tool/gui_walkthrough.sh drives two REAL desktop instances (separate
NEXUS_DATA_DIR + XDG_DATA_HOME), pairs them by clicking and typing into the
real widgets, and verifies each fetched file by size and sha256.

Where: Omarchy (Arch-based, Hyprland 0.56.2, Wayland), Flutter 3.47.5 /
Dart 3.13.4, commit 8a70ca2 plus the file-fetch working tree. Two Linux
desktop instances on one machine (loopback) — not a phone and not two hosts.

Full run dirs are regenerable: ./tool/gui_walkthrough.sh writes one under
/tmp/nexus_gui/<timestamp>/ (logs, 99_result.png, sizes/sha256). The run
below is /tmp/nexus_gui/20261004-203220.
